# GPU-102 — DeepStream media graph and typed candidate boundary

Status: implemented on `feature/GPU-102-deepstream`; GPU runtime qualification remains open

## Scope

U2 replaces the previous `gst_init`-only placeholder with a guarded DeepStream
7.0 media-plane boundary. The native API remains CPU-buildable and does not
import NVIDIA headers unless the explicit DeepStream option is enabled.

## Delivered

- Added an opt-in CMake SDK gate for the DeepStream metadata headers, GStreamer
  video package, and `nvdsgst_meta` library. A missing SDK root fails configure
  instead of silently building a pretend GPU path.
- Added a real graph builder for `nvurisrcbin` RTSP/file sources, NVDEC,
  bounded `nvstreammux`, PeopleNet Transformer `nvinfer`, NvDCF `nvtracker`,
  MediaPipe Tasks C++ GPU/EGL plugin boundaries, and GPU-local
  `gst-nvinferserver` SigLIP 2 crop inference.
- Added source reconnect properties and a bus callback that marks only the
  affected camera reconnecting. Existing per-camera bounded FIFOs and the
  broker-neutral `CandidatePublisher` bound memory and preserve retry order.
- Added an NvDs batch metadata probe that accepts only tracked person objects
  with valid source dimensions, timestamps, and confidence. It publishes the
  pixels-free `track.candidate.v1` envelope with correlated typed role receipts
  and unresolved revisions remain unavailable/fail-closed.
- Added readiness state that distinguishes compiled/runtime/constructed from
  qualified. Running a graph never implies a qualification pass; the one-stream
  and capacity receipt remains a GPU-107 responsibility.
- Added configuration shapes for PeopleNet, NvDCF, and SigLIP 2 plus explicit
  documentation that the MediaPipe plugins are required and may not be replaced
  by `identity` or CPU fallbacks. No weights, plans, private media, or SDK files
  were committed.
- Extended native tests for RTSP/file source validation, duplicate source
  isolation, graph-role description, bounded candidate ownership, and the
  CPU fail-closed message.

The DeepStream image is not imported on this host and host `pkg-config` has no
GStreamer development package. Therefore no DS7 compile, real NVDEC/decode,
PeopleNet/NvDCF, MediaPipe, Triton, RTSP, or throughput claim is made here.
GPU-101 must import the digest-pinned DS7 Triton image and the deployment must
provide the two reviewed MediaPipe plugins and exact model artifacts before
building with `TP_SMOKE_DETECT_ENABLE_DEEPSTREAM=ON`.
