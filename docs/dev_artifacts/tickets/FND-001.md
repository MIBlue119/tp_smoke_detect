# FND-001 — Repository foundation and v1 contracts

## Scope

Implemented U1 for R2, R9, and R15: CPU-safe Python packaging, typed v1 event
contracts, deterministic JSON Schema exports, safe Pydantic settings, example
configuration, quality gates, and an agent takeover guide.

## Files and ownership

- `pyproject.toml`, `uv.lock`: package metadata, CPU base, and optional groups.
- `src/tp_smoke_detect/`: settings, contracts, schema generator, and CLI.
- `proto/smoke/v1/`, `schemas/smoke/v1/`: broker and generated contract surfaces.
- `configs/*.example.yaml`: secret-free safe examples.
- `tests/unit/`, `tests/contract/`: settings and schema compatibility tests.
- `AGENTS.md`: takeover, GitFlow, verification, and artifact instructions.

## Verification evidence

- `uv lock` and `uv sync --group dev`: passed on CPython 3.12.10 with no CUDA
  libraries or model packages in the base profile.
- `uv run smoke-detect schema --output /tmp/tp-smoke-schemas` plus `cmp` against
  all three checked-in schemas: passed; generation is byte-identical.
- `uv run smoke-detect validate-config configs/camera.example.yaml`: passed.
- `uv run smoke-detect demo --fixture synthetic`: passed.
- `uv run ruff format --check .`: passed.
- `uv run ruff check .`: passed.
- `uv run mypy src tests`: passed.
- `uv run pytest tests/unit`: 7 passed.
- `uv run pytest tests/contract`: 5 passed.

The checked-in test suite verifies clean settings defaults, field-level errors
for duplicate camera vertices, negative limits, and unknown modes, typed v1
envelopes, no raw pixels, and schema compatibility.

## Notes

The v1 JSON schemas are generated from `contracts.py`; raw pixels and free-form
model prose are intentionally absent. Audio defaults to muted simulation mode.
