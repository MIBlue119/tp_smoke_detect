# INT-701 — Deployment and end-to-end qualification

Status: CPU/replay MVP-0 complete; GPU/site qualification explicitly blocked

## Scope delivered

- Added `deploy/Dockerfile.core` with a Python 3.11 locked build, non-root UID
  10001 runtime, read-only-friendly filesystem, and no runtime model/media
  fetching.
- Added `deploy/compose.yaml` for the local core, PostgreSQL migration target,
  metadata-only Mosquitto broker, Prometheus, and explicit `media`/`audio`
  profiles. The site network is Docker-internal; only API and Prometheus bind
  to loopback ports. The fake audio profile has no sound device.
- Added `deploy/image-pins.yaml` and a secret-file template documenting the
  digest/SBOM gate required before an air-gapped release.
- Added dependency-free `scripts/healthcheck.py`, media-free path-safe
  `scripts/backup_restore.py`, and `scripts/qualify_cpu.py`.
- Added an explicit `uvicorn` runtime dependency and settings-backed database
  and artifact roots so the container can start read-only with ephemeral
  defaults or persistent compose mounts.
- Added `tests/e2e/test_cpu_vertical_slice.py` covering replay candidate
  publication, cascade cycle/evidence decision, SQLite audit, shadow-mode
  `would_announce`, fake automatic audio, and append-only operator review.
- Added an opt-in GPU load marker that refuses to claim capacity when the
  target hardware harness is not enabled.
