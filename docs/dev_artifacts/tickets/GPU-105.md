Status: implemented; target-host qualification remains blocked until the

## Delivered

- Added `gpu-rtx3090` and disabled-by-default `gpu-vlm` Compose profiles.
- Isolated media, baseline Triton, MQTT, candidate consumer, core, and
  aggregate readiness on an internal network with no MQTT/Triton host ports.
- Reserved the NVIDIA device only for media/model services and set offline
  loader flags for model containers.
- Added immutable/read-only model mounts, Triton `model-control-mode=none`,
  startup wrappers, and independent health checks.
- Added `CandidateProcessingService` bootstrap to the API dependency graph and
  a broker-connected ready-file for the dedicated candidate consumer.
- Added `verify_gpu_bundle.py`, image export/import scripts, RTX 3090 runtime
  and model-profile configuration, and an aggregate readiness server.
- Updated the media image to the DeepStream 7.0/Triton 23.10 RTX 3090 row.
