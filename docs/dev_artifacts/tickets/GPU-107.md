# GPU-107 — One-stream, 20-stream, and fault-injection qualification

Status: implemented; target-host gates blocked with an evidence-bearing receipt.

Trust-boundary remediation: the qualification executor now requires signed
telemetry bound to the launched PID/start-time, host binding, and per-run
challenge; executor-captured `nvidia-smi` samples are the only accepted host
telemetry. Caller-injected `external_gpu_samples` are ignored/rejected. Fault
isolation likewise requires a signed bound attestation. One-stream readiness
derivation validates the complete qualification source before signing or
accepting it. The Compose GPU profile wires the pinned image digest and a
read-only receipt key, with an explicit preflight script for missing inputs.

## Delivered

- Added `scripts/qualify_gpu.py`, a fail-closed runner for the RTX 3090 lab
  profile. It probes the host and NVIDIA Docker runtime, attempts the exact
  digest-pinned DeepStream 7.0 Triton image import with a bounded timeout,
  checks container GPU/DeepStream tools, validates the model/engine manifest,
  validates a sealed local replay pack, and only then permits an operator-
  supplied real runtime command.
- Runtime telemetry accepts JSON lines from the reviewed pipeline and records
  scheduled/processed/dropped samples, queue depth/age, candidate latency,
  GPU/NVDEC utilization, and VRAM samples. Missing telemetry prevents a pass.
- Fault-injection requests are recorded explicitly. No timeout, OOM, stalled
  source, mismatch, queue-expiry, malformed-output, or reset result is inferred
  without a runtime-specific command and evidence.
- Added contract tests in `tests/gpu/test_one_stream.py` and
  `tests/load/test_gpu_qualification.py`.
- Added `tests/load/replay-pack.yaml` as a deliberately metadata-only shape;
  it cannot qualify until replaced by an approved sealed local bundle.
